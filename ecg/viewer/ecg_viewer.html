필터 버튼으로 원본이 어떻게 바뀌는지 골라 보세요. 단계별 보기는 원본→Median→High-pass→Notch→FIR을 한 화면에 쌓아 보여줍니다. 아래 막대를 끌면 구간 이동, 확대는 ＋／－·마우스 휠로.
필터는 원본(raw)에서 브라우저가 직접 계산합니다 — 아두이노 코드와 동일한 방식(이동평균 N=8, Median N=5, IIR α=0.7, High-pass R=0.99, Notch 60Hz, FIR 1:2:3:2:1). 심박수는 현재 선택한 신호의 R-피크로 계산되므로, 원본에선 부정확하고 필터를 거칠수록 정확해집니다.
JSON 형식: { "sample_rate_hz":250, "data":{ "t_ms":[…], "raw":[…] } } — ecg_record.py 파일을 그대로 불러오면 됩니다.
