위 연결 버튼을 눌러 ESP32 포트를 선택하세요. 먼저 아두이노 IDE의 시리얼 모니터/플로터를 닫아야 합니다(포트는 한 프로그램만 사용 가능).

시간창
실시간 표시: 새 값이 오른쪽에서 들어오며 왼쪽으로 흘러갑니다. 처리된 신호는 기기가 필터링해 보내는 값(예: ECG), 원본은 Raw. 심박(BPM)은 들어오는 신호의 R-피크로 실시간 추정합니다(ECG일 때 의미 있음). JSON 저장으로 지금까지 받은 구간을 파일로 내려받아 분석용 뷰어(ecg_viewer.html 등)에서 다시 볼 수 있어요.
Web Serial은 데스크톱 Chrome/Edge에서만 동작합니다. 파일을 더블클릭(file://)해서 열어도 되고, 만약 연결이 안 되면 이 파일이 있는 폴더에서 python -m http.server 실행 후 http://localhost:8000/bioamp_live_viewer.html 로 열어보세요.
입력 형식은 Raw:1234,ECG:56 또는 정수 한 줄(8431) 모두 인식합니다. baud는 스케치와 동일하게 — ECG·EOG·EEG는 115200, EMG는 250000.
